# CustomText Overlay — Minecraft 1.21.11 (Fabric)

This is a version-specific port using official Mojang mappings (required to resolve Minecraft classes for this remapped 1.21.11 build). of the original working CustomText Overlay source.

## Build (Windows)
1. Install a 64-bit Java 21 JDK and make sure `java -version` reports 21.
2. Open PowerShell in this project folder.
3. Run `gradle build`.
4. The remapped mod JAR is produced in `build/libs/`.

Install the JAR with Fabric Loader 0.18.4+ and Fabric API 0.141.3+1.21.11.

Editor shortcut: Ctrl + O.

This port has not been compiled or tested in-game in this environment. Build and test it before publishing.
